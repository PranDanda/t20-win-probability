    How good is it?

    The model was frozen before it saw any 2025–26 match, then scored once on all 1,539 of them. Lower log loss is better; it punishes confident wrong calls hardest.

    Against the betting market

    So this isn't a tool for beating bookmakers. Its value is showing why a match swung, which a price can't tell you.

    How it works

    1. The data. 1.99 million deliveries from 8,694 men's T20 matches since 2005, from Cricsheet: internationals, IPL, Big Bash, PSL, CPL, SA20, T20 Blast and Syed Mushtaq Ali.
    2. The match state. Before every ball: balls left, wickets in hand, runs, run rates and, in a chase, runs needed.
    3. The context. Team strength (an Elo rating tuned for home advantage and winning margins), each ground's par score and chase record, and the scoring era. All of it built only from matches played earlier.
    4. The models. A logistic regression and a gradient-boosted tree model for each innings, averaged. The trees are told that more wickets in hand can only help.
    5. The test. Trained on 2005–2024, tuned on 2024, then scored once on 2025–26 with the success criteria written down beforehand.
    6. The fix. Version 2 adds the runs a side can still expect from its balls and wickets left, which calms the model down when a chase is down to the tail. Rare collapses still catch it out: KKR needed 17 from 34 balls with two wickets left, and it gave them 97%.

    The full reasoning, including the experiments that failed, is in the project notes.
